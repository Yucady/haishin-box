# 配信準備BOX

配信前の準備から配信中の確認まで、必要な情報をひとつの画面で管理できる配信者向けWebアプリです。

![配信準備BOX](./public/og-image.png)

## アプリを開く

[配信準備BOXを使う](https://yucady.github.io/haishin-box/)

アカウント登録なしで利用できます。

## 主な機能

### 配信前の準備

- 配信タイトル・開始予定・URL・ハッシュタグの管理
- 配信開始までのカウントダウン
- 開始前のブラウザ通知
- よく使う配信設定のプリセット保存
- 自由に追加・削除できる準備チェックリスト

### 配信開始・配信中

- 配信状態・タイマー・X告知をまとめて開始
- 未完了の準備項目を開始前に確認
- 配信中に必要な機能だけを表示する集中モード
- 一時停止・再開に対応した配信タイマー
- クイックリンクと自動保存メモ

### 告知作成

- 定型文の保存・コピー
- 配信情報を差し込めるテンプレート変数
- 配信情報からX告知文を自動作成
- Xの文字数制限を考慮した文字数表示
- X公式投稿画面への受け渡し

### データ・PWA

- データのバックアップと復元
- PC・スマートフォンへのPWAインストール
- オフラインでの利用
- 新しいバージョンの更新通知
- 初回利用ガイドと再表示できる使い方説明

## データについて

入力内容は利用中のブラウザの `localStorage` に保存されます。

- 入力内容を外部サーバーへ送信しません
- 端末やブラウザごとにデータが分かれます
- ブラウザのデータを削除すると保存内容も消える場合があります
- 別の端末へ移す場合はバックアップ機能を利用できます
- Xへの投稿は、開いたXの投稿画面で確認してから行われます

## 対応環境

最新バージョンの主要なデスクトップ・モバイルブラウザを対象としています。

PWAのインストール方法やブラウザ通知の対応状況は、利用するブラウザや端末によって異なります。
